# Perception Capture Protocol

RQ3 capture is valid only when generated and manual arms use the identical sensor rig, calibration,
route, weather, synchronous settings, fixed delta, frame-completeness rule, and listener lifecycle.
Capture manifests must identify CARLA version, world/map hashes, calibration hash, route hash,
weather, frame counts, and software commit. Town10HD is a sensor-rig smoke/control dataset only and
cannot answer the Ingolstadt perceptual-domain question.

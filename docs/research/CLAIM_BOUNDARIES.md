# Claim Boundaries

`AUTHORITATIVE` means the governed evidence supports the stated claim. `BOUNDED` means the result
is valid only for the documented scope or method. `PROTOTYPE` is implementation evidence, not a
scientific result. `DEFERRED_RUNTIME` and `DEFERRED_EXTERNAL_DATA` identify missing external inputs.
`NOT_RUN` is absence of execution; it is never a pass. `SUPERSEDED` preserves an earlier artifact
without treating it as current.

Town10HD is sensor-rig control evidence only. Unlabeled embedding shift is not model-generalization
accuracy. Training on the manual target is not generated-to-manual transfer. Method improvements do
not establish map-quality improvements without the controlled thesis-vs-current comparison.

# v3 upgrade patch

Apply ONLY to a NEW COPY of the extracted v2 application, never to the verified original.
Copy the original release directory, extract this patch into the copy, retaining directory structure, then install .[gui] and optional .[gui-maps].
Use the complete v3 preview ZIP for independent installation or release traceability.
The v3 GUI was not renderer-tested in the build environment and requires Windows acceptance testing.
